# Xi Coin — Telegram Mini App

Мобильный clicker в стиле классических coin-кликеров. Это самостоятельная реализация с названием **Xi Coin**, без копирования чужих исходников или графики.

## Что уже есть
- тап по монете и начисление XI;
- энергия и автоматическое восстановление;
- прокачка силы клика;
- прокачка максимальной энергии;
- бустер x2 на 60 секунд;
- мгновенное восстановление энергии;
- ежедневный бонус;
- задания;
- экран рейтинга;
- адаптация под телефон;
- интеграция с Telegram WebApp SDK;
- сохранение прогресса в браузере через localStorage;
- имя и аватар пользователя берутся из Telegram, когда Mini App запущен внутри Telegram.

## Важно
Сейчас это готовый **клиентский MVP**. Баланс хранится на устройстве, поэтому это не настоящий серверный онлайн-баланс. Для реальной экономики, общего рейтинга, защиты от накрутки, реферальной системы и вывода средств нужен backend + база данных.

## Подключение к Telegram
1. Создать бота через @BotFather.
2. Создать Mini App / Web App для бота.
3. В качестве URL указать URL выше после публикации GitHub Pages.
4. Открывать Mini App через кнопку бота.

## Публикация
В репозитории GitHub откройте Settings → Pages → Source: GitHub Actions. Workflow `.github/workflows/pages.yml` публикует репозиторий как GitHub Pages.
