# Оракул — Telegram Mini App

Стартовая основа AI-платформы Таро, предсказаний и гороскопов. PHP 8+, MySQL, Telegram Web Apps и Telegram Stars (XTR).

## Уже добавлено
- Мобильный интерфейс Mini App.
- Каталог бесплатных и платных услуг.
- Проверка подписи Telegram initData на сервере.
- Создание invoice link для Telegram Stars.
- Таблица заказов и шаблон подключения ИИ.

## Настройка
1. Разместить файлы на PHP-хостинге с HTTPS.
2. Скопировать config.example.php в config.php на сервере и заполнить токен бота, ключ ИИ и параметры MySQL.
3. Импортировать database/schema.sql в MySQL.
4. В BotFather настроить Mini App URL на адрес сайта.
5. Настроить webhook Telegram на api/webhook.php (обработчик подтверждения оплаты и выдачи купленного результата — следующий этап).

Не загружайте config.php и секретные ключи в GitHub. До добавления webhook не включайте реальные продажи: приложение создаёт invoice, но подтверждение оплаты и выдача купленного результата ещё не реализованы. Платёж считается успешным только после получения successful_payment от Telegram.
